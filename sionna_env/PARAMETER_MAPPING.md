# Parameter Mapping: MATLAB Simulator vs. Sionna Environment

This document maps every model element between the reference MATLAB simulator (`defaultEnv_v17.m`, `generateChannel_v17.m`, `harqTransmit_v17.m`, `trafficInit_v17.m`, `trafficPre_v17.m`) and the Python/Sionna prototype environment (`sionna_env/`).

### Ground Rules & Classification Criteria
- **matches**: Assigned **ONLY** where the physical value and the underlying mathematical/simulation model are identical.
- **differs on purpose**: Deliberate architectural divergence (e.g. 5G NR numerology 1 at 30 kHz SCS vs. LTE numerology 0 at 15 kHz SCS).
- **differs**: Model formulation, value, or dynamics differ between the reference MATLAB implementation and the current Sionna prototype.
- **to do**: Feature or placeholder present in the prototype that requires full implementation against the target architecture (e.g. replacing placeholder AWGN threshold with offline Sionna LDPC BLER tables).
